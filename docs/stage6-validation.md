# Этап 6: навигация и клавиатурное управление

Добавлены список заголовков с переходом к выбранному заголовку, режимы Vim Normal/Insert/Visual и переключатель Vim-управления в настройках стартового экрана. При выключенном Vim редактор принимает обычный ввод. Настройки сохраняются между запусками. Верхнее меню можно скрыть; кнопка навигации по заголовкам тогда остаётся в нижней полосе.

В первой версии обработаны `h/j/k/l`, `w/b/e`, `0/$`, `gg/G`, `i/a/o`, `Esc`, `x`, `dd`, `yy`, `p`, `u`, `/`, `n`, Visual-выделение и цифровые повторы движений. Команды Normal/Visual ориентируются на физические клавиши и имеют перевод русских букв, если код клавиши недоступен. `Ctrl-W s/v` и `:split`/`:vsplit` создают ещё одно окно того же документа; `Ctrl-W w/W/p/h/j/k/l` переключают окна. На Android направления работают как переход к соседней задаче документа.

Окна одного документа обмениваются содержимым через `BroadcastChannel`. Фокусное окно принимает ввод, другое временно становится доступным только для чтения. Одно окно отвечает за фоновую запись DOCX, чтобы очереди не конкурировали. Пока передаётся полный снимок документа: быстрый переход между окнами во время набора и восстановление после закрытия основного окна нужно проверить на реальных устройствах до признания этапа завершённым.

Проверены `npm run build`, Windows `tauri build --debug --no-bundle` и Android ARM64 `tauri android build --debug --target aarch64 --apk --ci`. Ручная проверка клавиатуры и окон на ПК и телефоне пока не выполнена.
