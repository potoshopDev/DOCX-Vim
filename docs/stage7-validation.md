# Этап 7: проверка текста и помощь при наборе

Реализовано в общей кодовой базе Windows и Android:

- Орфография русского и английского языков по локальным словарям Hunspell через `nspell`. Словари загружаются в Web Worker; неверные слова подчёркиваются без изменения DOCX. Нажатие на слово показывает варианты, замену, игнорирование и «Добавить в словарь». Пользовательский словарь хранится локально отдельно от документов, работает во всех документах и редактируется в настройках стартового экрана.
- Грамматика подключается только после ввода собственного адреса LanguageTool в настройках. Запросы идут после паузы набора; неизменённые фрагменты берутся из кэша, устаревшие ответы отменяются. Публичный бесплатный сервер LanguageTool запрещён в настройке. Для Windows и Android используется HTTP-плагин Tauri, чтобы собственный сервер не зависел от CORS WebView. Поддерживаются HTTPS-серверы и локальные HTTP-адреса (`localhost`, `127.0.0.1`, `10.0.2.2`). При недоступности сервера локальная орфография продолжает работать.
- При вводе `--` заменяется на `—`; прямые двойные кавычки заменяются на «ёлочки» по контексту. Замена производится транзакцией редактора и попадает в историю Undo. Настройка включения находится на стартовом экране.
- После короткой паузы ввода показывается подсказка из словаря. `Tab` и `Ctrl+Space` принимают её, `Ctrl+Space` без подсказки повторяет поиск, `Esc` скрывает. Подсказки включаются и выключаются в настройках.
- Автозамена и подсказки работают при обычном вводе и в режиме Vim Insert; команды Normal/Visual они не перехватывают.

Проверено: `npm run build`, Windows `tauri build --debug --no-bundle`, Android ARM64 `tauri android build --debug --target aarch64 --apk --ci`; отдельно проверено распознавание корректных и ошибочных русских и английских слов словарным движком. Ручная проверка набора и нажатий в Windows и Android оставлена пользователю по его запросу.

Ограничения для проверки на устройстве: качество вариантов зависит от словарей Hunspell; распознавание грамматики зависит от настроенного сервера. Разметка проверяется по текстовым фрагментам, поэтому правило грамматики на границе разных форматированных фрагментов может не сработать. При наборе с Bluetooth-клавиатуры отдельно проверить `Tab`, `Ctrl+Space`, кавычки и Undo после автозамены.

Словари взяты из пакетов [`dictionary-ru`](https://github.com/wooorm/dictionaries/tree/main/dictionaries/ru) (BSD-3-Clause) и [`dictionary-en`](https://github.com/wooorm/dictionaries/tree/main/dictionaries/en) (MIT и BSD). Тексты лицензий находятся рядом со словарями в `app/public/dictionaries/`.
