# Проверка этапа 4

## Реализовано

- После выбора места сохранения DOCX обновляется автоматически. Снимки документа записываются последовательно; экспорт выполняется в Web Worker, поэтому набор текста не ждёт создания ZIP.
- Перед записью выбранного файла сохраняются черновик и резервный DOCX в каталоге данных приложения. Черновик пишется через временный файл и переименование. При неудачной записи выбранного файла локальные данные остаются, очередь повторяет попытку.
- При первом сохранении импортированного файла предлагается имя с суффиксом `(DOCX Vim)`; исходный файл по умолчанию не перезаписывается. Следующая команда «Сохранить DOCX» использует уже выбранное место без повторного диалога.
- Android сохраняет разрешение на URI, если системный документ-провайдер разрешает постоянный доступ.

## Проверено 23.10.2026

- `npm run build` и сборка Android x86_64 прошли.
- На Android API 36 системный выбор открыл файл `Документ (2).docx` из локальной папки Downloads. Кириллица отображалась правильно.
- Сохранение через Android document provider создало новый DOCX. После изменения текста фоновое сохранение обновило его без нажатия кнопки. После сокращения текста DOCX остался корректным ZIP, размер уменьшился.
- После принудительной остановки приложения черновик восстановился. Запись в ранее выбранный URI продолжилась после перезапуска. Резервный DOCX и черновик присутствуют в каталоге данных приложения.
- Изменение текста непосредственно перед уходом приложения в фон сохранилось в DOCX; файл остался корректным ZIP.
- На длинном файле `квест1.docx` (около 2900 слов) два последовательных изменения попали в автоматически обновлённый DOCX. Архив остался корректным, исходный файл не перезаписывался.
- Сборка Windows прошла с установленным Visual C++ toolchain. Проверка системного диалога в запущенном окне не завершилась: средство захвата окна дважды вернуло тайм-аут. Открытие и сохранение через диалог на Windows остаются ручной проверкой перед закрытием этапа.

Содержимое пользовательских DOCX и файлы, созданные при проверке, не публикуются.
