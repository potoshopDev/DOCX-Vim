# Релизные сборки

Готовые Windows и Android файлы копируются в локальную папку `build/prod/`; папка исключена из Git. Windows собирается в режиме release как исполняемый файл и NSIS-установщик. Android собирается в режиме release для ARM64 и подписывается локальным ключом.

Windows EXE и установщик пока не подписаны сертификатом издателя; при запуске Windows может показать предупреждение SmartScreen. Для публичного распространения потребуется сертификат подписи кода.

Ключ Android находится в `app/src-tauri/gen/android/docx-vim-release.jks`, а параметры подписи — в `app/src-tauri/gen/android/keystore.properties`. Оба файла исключены из Git. **Сохраните их вместе в защищённой резервной копии:** без того же ключа нельзя выпустить обновление установленного релизного APK с прежним идентификатором приложения. Не публикуйте эти файлы и пароль. Сборка без локальных параметров подписи создаст неподписанный релизный APK, который нельзя распространять как готовую установочную версию.

Предыдущие тестовые APK были подписаны отладочным ключом. Для установки релизного APK с тем же идентификатором Android может потребовать удалить отладочную версию; перед удалением сохраните нужные документы и черновики.
