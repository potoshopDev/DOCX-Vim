# Текстовые команды Vim

Команды работают в режимах Normal и Visual на английской и русской раскладках. Например, физические клавиши `h/j/k/l` при русской раскладке дают `р/о/л/д`. В Insert текст вводится в выбранной раскладке без преобразования. `Esc` возвращает Normal; в настройках стартового экрана Vim можно отключить.

| Группа | Команды |
| --- | --- |
| Ввод | `i`, `I`, `a`, `A`, `o`, `O`, `R`, цифровые повторы, включая `5o` и `5O` |
| Движения | `h/j/k/l` (`j/k` переходят между видимыми строками с учётом переноса текста), `0`, `^`, `$`, `w/b/e`, `W/B/E`, `ge`, `gg/G`, `{`/`}`, `%`, `f/F/t/T`, `;`/`,`, `H/M/L`, `Ctrl-d/u/f/b`, `zz` |
| Операции | `d/c/y` с движением, `dd/cc/yy`, `D/C/Y`, `x`, `r`, `p/P`, `J`, `u`, `Ctrl-r`, `.` |
| Текстовые объекты | `iw/aw`, `iW/aW`, парные скобки и кавычки после `d/c/y` или в Visual. `daw`, `ciw`, `de` и похожие сочетания. `da` ожидает букву объекта: например, `daw` — удалить слово с прилегающим пробелом. |
| Выделение | `v` — посимвольное, `V` — выделение видимой строки; `j/k` расширяют выделение по строкам, `d/c/y` действуют на него |
| Поиск | `/` вперёд, `?` назад вводятся в закреплённой нижней строке; `n/N` повторяют поиск в нужном направлении, `*` ищет слово под курсором |
| Окна и файл | `Ctrl-W s/v` и `:split`/`:vsplit` создают отдельное окно текущего документа; `Ctrl-W w/W/p/h/j/k/l` переключают окна; `:w` сохраняет DOCX, `:q` закрывает редактор после сохранения черновика, `:wq` сохраняет DOCX и закрывает редактор, `:wqa` сохраняет DOCX во всех открытых документах и закрывает их окна |

Основа движений и операторов сверена со [справочником Vim](https://vimhelp.org/quickref.txt.html); реализация опирается на [vim-prosemirror](https://github.com/KevinChristian30/vim-prosemirror). Работа с файлами рядом и Vim-скрипты не входят в текстовые команды этого этапа.
