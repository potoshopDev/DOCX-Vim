# Одновременное открытие документа в нескольких окнах

Каждый DOCX имеет одну сессию в процессе Tauri. Сессия хранит последнюю принятую версию документа, номер версии и окно с правом редактирования. Новое окно сначала получает снимок сессии и открывается только для просмотра. При переходе в него приложение запрашивает право редактирования. Прежнее окно прекращает ввод, дожидается передачи правок и фонового сохранения, останавливает свою очередь облачной записи и освобождает право. Новое окно получает актуальный снимок, после чего включает ввод. Остальные окна получают изменения с номером версии и остаются доступными для просмотра.

Сохраняет активное окно, используя документ из общей сессии, а не свою устаревшую копию редактора. Сначала обновляется резервный черновик, затем выбранный локальный или облачный источник. При закрытии окна сессия остаётся доступной другим окнам; после закрытия последнего окна удаляется из памяти. При новом открытии источник читается заново.

На Android прежний WebView может быть приостановлен системой. Если он не ответил на запрос передачи, новое окно получает право редактирования после ожидания. До подтверждения завершения предыдущей записи новые правки сохраняются отдельным восстановимым черновиком; основной DOCX и облако не перезаписываются. После подтверждения новая версия сохраняется в выбранный источник. Если поздняя правка прежнего окна уже не может быть принята сессией, она также сохраняется отдельным черновиком.

Ручная проверка на обеих платформах:

1. Открыть один DOCX в двух окнах и быстро печатать в первом во время открытия второго. Во втором должен появиться весь введённый текст.
2. Переключаться между окнами, вводить по строке в каждом и убедиться, что обе строки остаются в обоих окнах и в сохранённом DOCX.
3. Убедиться, что неактивное окно показывает текст, но не принимает команды изменения; после переключения курсор и ввод работают в новом окне.
4. Закрыть первое окно во время фонового сохранения, продолжить во втором и проверить DOCX и черновик после перезапуска.
5. Повторить с файлом Яндекс Диска, включая отключение сети и последующее восстановление соединения. При конфликте основным остаётся выбранный облачный файл, прежняя версия доступна в черновиках.
