# DOCX Vim

Основа приложения: Tauri 2, React, TypeScript и Tiptap. Доступны базовое форматирование, крупный мобильный вид и вид страницы, открытие DOCX, стартовый экран, отдельные окна документов, навигация по заголовкам и первая версия Vim-управления с переключением на обычный ввод. Черновики восстанавливаются; после первого выбора места сохранения DOCX обновляется в фоне с локальной резервной копией. Импорт и экспорт сейчас поддерживают прежде всего текст, заголовки, простые списки и форматирование. Таблицы, изображения, колонтитулы и другие сложные элементы Word пока не сохраняются; при первом сохранении импортированного файла предлагается отдельное имя. Сообщения об ошибках в интерфейсе не показываются. Ручная проверка этапа 6 и синхронизации одновременных правок в двух окнах описана в `../docs/stage6-validation.md`. Проверка текста и облачные файлы запланированы в `../docs/roadmap.md`.

## Разработка

```powershell
npm install
npm run tauri dev
```

Android-проект уже создан в `src-tauri/gen/android`. Для локальной проверки на эмуляторе:

```powershell
npm run tauri android dev
```

## Проверка сборки

```powershell
npm run build
npm run tauri -- build --no-bundle
# Эмулятор x86_64:
npm run tauri -- android build --debug --target x86_64 --apk --ci
# Телефон с ABI arm64-v8a:
npm run tauri -- android build --debug --target aarch64 --apk --ci
```

Обе команды записывают APK в `src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk`, поэтому после новой сборки предыдущий файл заменяется. Для реального Android-устройства ещё нужны испытания с Bluetooth-клавиатурой; для выпуска понадобится отдельная подпись.

Проверенный APK для телефона (`arm64-v8a`) дополнительно скопирован в `../builds/DOCX-Vim-0.1.0-arm64-v8a-debug.apk`. Папка `builds/` локальная и исключена из Git; этот файл подписан отладочным ключом и предназначен для ручной проверки установки.

Исходный код распространяется по [лицензии MIT](../LICENSE). Пользовательские примеры DOCX из `../e/` в репозиторий не включаются.
